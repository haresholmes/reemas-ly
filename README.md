## 💎 الهوية البصرية والمفاهيم الفنية (Brand Identity & Concepts)

تم تصميم الهوية البصرية وفق أرقى معايير المينيماليزم العالمية لكبرى دور المجوهرات (Haute Joaillerie)، وتضم:
- **36 مفهوماً فنياً خالصاً** مرسومة من الصفر بريشة فنان (بدون طابع الأختام التقليدية).
- **محاكاة بصرية حية** على سبائك الذهب الخالص عيار 24K، علب المخمل الكحلية الملكية، بطاقات الأعمال الفاخرة، وواجهات المعارض.
- **أداة مقارنة تفاعلية جنباً إلى جنب** لاختيار أفضل شعار بدقة.

### لوحة الألوان الرسمية (Brand Palette):
- **الكحلي الداكن الملكي (Royal Deep Navy):** `#03070E` / `#0A192F`
- **الذهب الخالص اللامع (Imperial Gold):** `#D4AF37` / `#FFF0B8` / `#E5C058`
- **الأبيض النقي والعاجي:** `#FFFFFF` / `#F8F5EE`

## 📂 بنية المشروع (Repository Structure)

```text
reemas-ly/
├── index.html               # موقع الشركة الرئيسي المتكامل
├── css/
│   └── style.css            # أنماط وتنسيقات الموقع الفاخرة (Dark/Light)
├── js/
│   └── main.js              # التفاعلية، حاسبة الجملة، شريط أسعار الذهب، ثنائي اللغة
├── assets/                  # أصول الموقع، صور السبائك 3D، الأيقونات والشهادات
├── logo-lab/                # مختبر استوديو الشعارات (36 مفهوماً فنياً)
│   ├── index.html           # منصة الاستعراض، الفلاتر، المقارنة والمحاكاة الحية
│   ├── assets/              # ملفات الـ 36 شعاراً المفتوحة بدقة Vector SVG (الخطوط مضمّنة داخل كل ملف)
│   ├── tools/refine_logos.py # سكربت إعادة رسم الشعارات الضعيفة وتضمين خطي IBM Plex Sans Arabic و Jost
│   └── server.py            # خادم العرض المحلي المستقل
├── .nojekyll                # تهيئة استضافة GitHub Pages
└── README.md                # وثيقة المشروع الرسمية
```
